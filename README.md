# \# 🛡️ CyberSafe — Interactive Cybersecurity Awareness and Threat Detection Simulator

# 

# CyberSafe is a web-based cybersecurity awareness and threat detection simulator designed to help users recognize and understand common online threats through interactive, scenario-based challenges.

# 

# The platform provides realistic cybersecurity situations where users identify whether a message, URL, email, or online interaction is Safe, Suspicious, or a Scam. It also provides explanations and tracks user performance to encourage safer digital habits.

# 

# \## 🌐 Live Demo

# 

# \*\*Live Website:\*\* \[https://cybersafe-project.site.je](https://cybersafe-project.site.je)

# 

# \## ✨ Key Features

# 

# \- \*\*Interactive Challenges:\*\* Practice identifying different cybersecurity threats.

# \- \*\*Phishing Email Detection:\*\* Identify suspicious and fraudulent emails.

# \- \*\*Scam SMS Detection:\*\* Recognize potentially fraudulent text messages.

# \- \*\*Fake Job Detection:\*\* Learn to identify suspicious job offers.

# \- \*\*Suspicious URL Detection:\*\* Understand warning signs in potentially harmful links.

# \- \*\*User Authentication:\*\* Registration and login functionality.

# \- \*\*Score and XP System:\*\* Earn points and experience through challenges.

# \- \*\*Progress Tracking:\*\* Monitor performance through the user dashboard.

# \- \*\*Admin Panel:\*\* Manage and monitor the platform.

# \## 🚀 Getting Started

# 

# 1\. Clone this repository.

# 2\. Set up a local PHP and MySQL environment using XAMPP.

# 3\. Import the provided database SQL file into phpMyAdmin.

# 4\. Configure your database connection using the example configuration.

# 5\. Place the project inside the XAMPP `htdocs` directory.

# 6\. Start Apache and MySQL.

# 7\. Open the application in your browser.
